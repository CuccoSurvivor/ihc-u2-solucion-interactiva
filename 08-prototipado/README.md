# 8. Prototipado

Responsable: Demis Palomera

El apartado cuenta con dos versiones complementarias del prototipo de media fidelidad: una versión web navegable y otra en Figma. La versión web permite probar algunas interacciones directamente; la versión de Figma contiene pantallas editables y conexiones para recorrer los flujos en modo presentación.

## Enlaces

- **Figma:** https://www.figma.com/design/qascquLzTrJLtCRihyw5VI (pantallas editables y conexiones; la lectura en voz alta y el dictado funcionales no se ejecutan en Figma).
- **Versión web:** [Abrir prototipo en GitHub Pages](https://hymisx-dotcom.github.io/ihc-u2-solucion-interactiva/).
- **Código del prototipo web:** carpeta `prototipo`; se puede descargar y abrir `index.html` con Chrome o Edge. En otros navegadores algunas funciones de voz pueden no estar disponibles.

En la versión web, arriba a la izquierda hay un selector para verla como computador o como celular.

## Pantallas de la versión web

| Pantalla | Qué se puede hacer |
| --- | --- |
| P1 Inicio | Ver los cursos y el botón Aa en la barra de arriba |
| P2 Curso | Entrar al contenido, al foro o a la clase en vivo |
| P3 Contenido | Leer el texto. Cuando se escucha, la frase que se está leyendo queda marcada |
| P4 Panel Aa | Modo oscuro, tamaño de letra (4 niveles), escuchar la página y elegir la velocidad |
| P5 Foro | Dictar una respuesta con el micrófono |
| P6 Clase en vivo | Hacer zoom a la diapositiva (pellizco, doble toque o botones) |

Las capturas de cada pantalla están en la carpeta `capturas`.

## Tarea principal en el prototipo

1. Entrar a Interacción Humano Computador desde Mis cursos.
2. Abrir la ficha de actividad de la Unidad 2.
3. Abrir el panel con Aa y activar el modo oscuro o agrandar la letra.
4. Apretar Escuchar, pausar y cambiar la velocidad.
5. Apretar Detener y seguir leyendo normal.

## Alcance y limitaciones

- En la versión web, los ajustes se guardan en el navegador y no en una cuenta real; por eso no se sincronizan entre dispositivos.
- Si el navegador no tiene una voz en español o no permite usar el micrófono, la lectura en voz alta o el dictado pueden no funcionar como se espera.
- Si el navegador no dispone de reconocimiento de voz, el prototipo muestra un texto de ejemplo para representar el dictado.
- La clase en vivo corresponde a una diapositiva de muestra; no es una conexión real a Blackboard Collaborate.
- En Figma se pueden recorrer las pantallas y conexiones en modo presentación, pero las funciones de voz se prueban en la versión web.
