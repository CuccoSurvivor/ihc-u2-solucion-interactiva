# 9. Uso de GitHub

Responsable: Demis Palomera

En el repositorio dejamos cada apartado en su carpeta, el prototipo y lo que fuimos acordando como grupo. En esta carpeta hay dos archivos:

- [registro-avances.md](registro-avances.md): qué subió cada uno y cuándo.
- [acuerdos.md](acuerdos.md): cómo nos repartimos el trabajo, qué decidimos del diseño y cómo trabajamos en el repositorio.

El historial de commits también sirve de respaldo, porque ahí queda cada cambio con el nombre de quien lo hizo.
